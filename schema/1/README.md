# KStory content schema 1

Schema `1` is the canonical authoring contract for KStory projects. It is intentionally stable: adding content does not change the schema version, and a new version requires an explicit migration.

The JSON Schemas in this directory describe structure. The Rust validator remains responsible for cross-file rules such as references, graph reachability, callbacks, tokens and translation states.

- `content.schema.json` applies to `stories.json`, `dialogues.json`, `quests.json`, `items.json`, `entities.json` and `callbacks.json`.
- `locale.schema.json` applies to `locales/en.json` and target locale files.
- `keys.schema.json` applies to `keys.json`.

The `runtime/` directory is generated by `export` and is not part of the authoring source of truth.
